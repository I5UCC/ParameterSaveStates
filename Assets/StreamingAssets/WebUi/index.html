Profiles

Profile Management

Copy or delete all profiles for a saved avatar.

Backup / Restore

Export all saved profiles and settings (profile filters, auto sync and fixed parameters, global and per avatar, plus the theme) to a zip archive. Importing a zip restores them and overwrites any existing files with the same name; other existing files are kept.

Apply Profile Filters

Global Filters

Per-Avatar Filters

Applied in addition to global filters for the selected avatar.

Parameter Auto Sync

Global Auto Sync

When switching to any avatar, the listed parameter names are copied from the previous avatar's last known values.

Per-Avatar Auto Sync

Applied in addition to global auto sync when switching into the selected avatar.

Fixed Parameters

Parameters set to a fixed value whenever you switch to an avatar. Applied after auto sync, so a fixed value wins over a synced one. Not sure which value is needed? Add the names (value optional), then use “Fill values from profile” to copy the values and types from a saved profile of any avatar. Review the list, then save.

Global Fixed Parameters

Set for every avatar.

Per-Avatar Fixed Parameters

Set for the selected avatar only. Overrides a global entry with the same name.
